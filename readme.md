# Gerenciador de Tarefas Simples (CLI) 📝

Projeto desenvolvido para o **Projeto Integrador: Profissional de T.I. Empregabilidade e Portfólio**.

## 📌 Sobre o Projeto
Uma aplicação em linha de comando (CLI) desenvolvida em Python para gerenciamento de tarefas do dia a dia. O sistema permite criar, listar e marcar tarefas como concluídas, mantendo os dados salvos localmente em um arquivo JSON.

## 🚀 Funcionalidades
- **Adicionar Tarefas:** Insira novas tarefas na lista.
- **Listar Tarefas:** Visualize o status (concluído/pendente) de cada tarefa.
- **Concluir Tarefas:** Atualize o estado de uma tarefa com um comando simples.
- **Persistência de Dados:** As tarefas ficam salvas localmente via JSON.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Estrutura de dados:** Dicionários e Listas em JSON

## 💻 Como Executar
1. Certifique-se de ter o Python 3 instalado.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do arquivo e execute:
   ```bash
